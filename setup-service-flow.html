8. Legend + conventions

Gate / decision point Script invocation Owner prompt (ask_user) File write (per-answer) Halt / failure path
Incremental persistence rule: Every ask_user answer is written to disk before the next prompt. Buffering answers in memory and dumping at the end is a bug. The chat session being killed mid-wizard never loses an answer; re-running setup-service picks up exactly where it left off.
Script vs AI: Scripts are dumb extractors (find params, find EV2 inputs, find SDS references, return JSON). The agent is the judge (decide what those facts mean, propose params, detect drift, render diffs). Clean separation — deterministic where it matters, flexible where it helps.
